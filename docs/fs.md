# fs

Filesystem process. The kernel does not open files. A guest is bound to an
`fs` process and calls this class. `fs-ts` implements it on a host directory.
There is no second C++ server.

Header: `include/waos/fs.hpp`. Target: `waos_fs`.

Paths are relative to the process root. The host rejects an empty path, a
NUL, an absolute path, and any `..` segment.

## Methods

| id | method |
| --- | --- |
| 0 | `mkdir(path)` |
| 1 | `rmdir(path)` |
| 2 | `readdir(path)` |
| 3 | `unlink(path)` |
| 4 | `rename(from, to)` |
| 5 | `stat(path)` |
| 6 | `exists(path)` |
| 7 | `open(path, flags)` |
| 8 | `close(id)` |
| 9 | `write(id, data)` |
| 10 | `read(id, max_bytes)` |
| 11 | `seek(id, offset, whence)` |
| 12 | `sync(id)` |

## Types

`open_flag`: `READ`, `WRITE`, `CREATE`, `TRUNCATE`, `APPEND`.

`seek_whence`: `SET`, `CUR`, `END`.

`file_info`: `is_directory`, `size`, `mtime_ms`.

`dir_entry`: `name`, `is_directory`, `size`.

## Exceptions

`fs_error`, `fs_not_found`, `fs_already_exists`, `fs_not_a_directory`,
`fs_is_a_directory`, `fs_invalid_path`, `fs_invalid_handle`,
`fs_invalid_flag`, `fs_io_error`.

## Adding a method

Append it on `class fs` and on the checked-in `fsApi.ts`. This header is the
source. The TypeScript file is not regenerated by this repository.
